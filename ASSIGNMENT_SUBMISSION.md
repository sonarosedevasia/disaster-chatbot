### 1. Hazard Chosen & Problem Scope
Floods represent India's most recurring and economically devastating natural hazard, with Kerala suffering catastrophic deluges in 2018 and subsequent flash floods and landslides in the Western Ghats (e.g., Wayanad). 

During severe flooding, citizens often experience panic, telecommunications degradation, and conflicting misinformation on social media. SafeKerala provides clear, deterministic, step-by-step guidance to ensure citizens prioritize life safety (higher floors, avoiding floodwater, electrical disconnection protocols) and reach emergency authorities (112, 1070, 1077) without ambiguity.

### 2. How to Run the Working Chatbot

#### A. Web Version (Flask)
1. Ensure Python 3.10+ is installed.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Start the application:
   ```bash
   python app.py
   ```
4. Open your web browser and navigate to:
   ```
   http://127.0.0.1:5000/
   ```
5. Click **"Start Flood Guidance"** to launch the interactive emergency assistant.

### 3. Decision-Tree Flowchart

The assignment requires a decision tree flowchart with at least 3-4 branches. SafeKerala implements an automated pipeline where `flowchart.mmd` is generated directly from `data/trees/flood.json` to guarantee 100% parity with code.

**Key branches in the Flood Decision Tree**:
1. **Branch A (Indoors)**: Evaluates building elevation, low-lying flood susceptibility, water ingress, and electrical disconnection safety.
2. **Branch B (Outdoors)**: Guides evacuation away from overflowing streams, forbids crossing moving water ("Turn Around, Don't Drown"), and steers to high ground.
3. **Branch C (Inside a Vehicle)**: Evaluates stalling risk, mandates immediate vehicle abandonment before water reaches 6 inches, and instructs roof climb if trapped.
4. **Branch D (Vulnerable Persons / Receding Water)**: Special protocols for elderly/disabled residents and post-flood sanitation/contamination checks.

The complete Mermaid source code is located at [`flowchart.mmd`](flowchart.mmd). You can view the diagram rendered interactively in the web application under the **Flowchart Visualizer** tab (`/flowchart`) or in GitHub/Mermaid Live Editor.
